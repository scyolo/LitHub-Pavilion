## 性能证据

| 指标 | 优化前 | 优化后 |
|---|---:|---:|
| 首页元数据体积 | 480,693 字节 | 313,923 字节 |
| 首页请求数 / 论文分片请求数 | 2 / 0 | 2 / 0 |
| 同一 141,496 篇快照的检索测试读取量 | 45,991,855 字节 | 29,238,317 字节 |

首页体积降低约 34.7%，同时快照论文量增加约 30.7%。独立 reader v4 描述文件只在论文浏览或检索时加载；仍校验哈希与快照身份。

扩大至 184,993 篇后的检索测试：所有标题索引身份核验通过；33 次精确标题、8 次智能模式、22 次方向限制、8 次不相邻关键词 AND 检查通过。全套耗时 5,274 ms，不应拿变化后的查询样本直接宣称同比加速。

Chromium 本地生产预览：无概览缓存的首页 303 ms；人为延迟 manifest 5 秒后，缓存首页 239 ms 显示，不等待版本检查。新增 IJHCI 3,489 篇可浏览；390px 移动端无横向溢出，B 类期刊筛选、主题切换、日历通过。实际完整标题检索 108 ms（已浏览来源后的场景），详情读取一个压缩分片，官方 DOI 链接保留，无页面异常。

**以上是本地验证，不是公网、低端手机或所有查询的速度保证。**
