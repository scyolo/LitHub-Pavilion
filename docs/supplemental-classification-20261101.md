# 现有 28 个方向内的补充标注（2026-11-01）

## 范围与结论

上一轮结束后仍有 37,048 篇 CCF A/B 论文未命中任何方向。本轮按“先判定是否属于现有 28 个方向，属于则补充，不属于不新建方向”的口径复核这批论文，新增 17 条标题规则和 4 条来源先验，覆盖 12 个既有方向；方向总数保持 28 个。

- 未命中任何方向的论文由 37,048 篇降至 **32,240** 篇；首次获得方向标签的论文由 376,755 篇增至 **381,563** 篇。

- 论文主表仍为 413,803 篇，人工标签 5 条不变，来源目录、方向定义、公开准入规则均未改变。
- 既有 28 个方向中 16 个标签数量完全不变，12 个只增不减；逐方向增量与重算前的模拟完全一致。
- 本轮不提交、不推送、不部署。

同期复核并放弃了几类候选扩充：

- **生物信息/医学信息**：医学影像与临床机器学习标题中只有 4 条强命中，规则覆盖率过低，不值得单独维护一条易误报的规则。
- **广义理论与算法**：`algorithm`、`optimization`、`approximation` 等泛词可命中 2,739 篇，但绝大多数是数据挖掘、工程优化与应用论文，会成为整库噪声。

- **广义软件工程**：`code`、`testing`、`verification` 等泛词可命中 263 篇，多为通用测试或验证论文，增量有限且误报风险高。

- **`TAC` 计入 `hci`**：情感计算、情绪识别、可穿戴与生理信号是 HCI 的典型子领域，且已由本轮 `hci-affective` 标题规则独立验证。

## 复核与精化

每条规则先在未命中论文中抽样检查标题，再对易混词收紧正则；首轮草稿中暴露的误报与处理：

| 方向 | 首轮问题 | 精化 |
| --- | --- | --- |
| `retrieval` | 裸 `recommendation(s)` 命中“Design Recommendations”“Security Recommendations”“Recommendations for Future Research”等非推荐系统标题 | 对 clinical/medical/policy/treatment/practice/design/security/safety/care/research/guideline/future/management/ethical/legal 加负向后顾，并对 “for future/further/policy/practice/research/design/analys/clinical” 加负向前瞻 |
| `speech` | 裸 `acoustic` 命中地球物理与水声，`sound` 命中 “soundness”，`music` 命中音乐认知，`speaker` 命中人物，`speech detection` 命中仇恨言论，`target tracking` 命中雷达/声呐 | 改为音频、麦克风阵列、声事件、空间音频、音乐信息检索、说话人分离/定位等技术短语；排除 `magnetotelluric audio`；仇恨言论归 `nlp` 而非 `speech` |
| `graph` | `network embedding` 命中虚拟网络嵌入与神经网络表示学习 | 移除该词条，改用 GNN、节点分类、图表示、图重连、图粗化 |
| `cv` | 裸 `change detection` 命中概念漂移与环境变化检测 | 对 concept/drift/environmental/adaptive 加负向后顾 |
| `ml` | 裸 `boosting` 命中 “Boosting ...” 句式标题 | 只保留 gradient boosting、AdaBoost、XGBoost |
| `systems` | 裸 `data management` 命中通用数据管理论文 | 要求 cloud-native、cloud database、distributed database/index/query/key-value 或 data management systems |
| `hci` | 裸 `visualization` 范围过宽 | 保留，因为可视化本身即 HCI 子领域；命中 979 篇、新增 466 条标签，抽样未见系统性误报 |

`security` 的隐私规则同样避免裸 `privacy`，只匹配 privacy-enhanced/preserving/protection/leakage、location privacy、k-anonymity、anonymization、geo-indistinguishability 等复合词；`nlp` 的虚假信息规则要求 misinformation/disinformation/fake news/rumour 等明确词，不匹配泛化的 `news`。

## 边界

- 方向标签表示主题相关性，不是精确的方法论文清单。来源先验会整刊标注，标题规则仍可能产生跨领域误报；例如可视化规则会命中非 HCI 语境的可视化论文，用户研究规则可能命中医学或教育领域的用户研究。
- `recommendation` 的负向断言排除了设计、临床与政策建议类标题，也会漏掉少数确实属于推荐系统的“Design Recommendation”论文，这是为避免整库误报而接受的取舍。
- 剩余 32,240 篇未命中论文主要来自 28 个方向之外的领域：ICASSP 信号处理 4,353 篇、TGARS 遥感 4,160 篇、CogSci 认知科学 2,929 篇、TITS 交通 2,537 篇、Information Sciences 2,347 篇、TSMC 2,044 篇、Cybernetics 1,570 篇、AEI 工程信息 1,370 篇、TFS 1,113 篇、Cognition 913 篇、SCIS 903 篇、TCSVT 894 篇、TKDE 803 篇、TEC 590 篇。继续覆盖需要新增遥感/地学、控制/控制论、认知科学、交通等方向，属于分类体系决策；本轮按既定口径不新增方向。
- 本轮只改变方向分类与标签，不改变论文数量、来源目录、公开准入规则或前端筛选契约，也不代表 CCF A/B 论文已完整收齐。
- 本地快照已在本地重新导出，但本轮没有提交、推送或部署；线上仍为此前发布的快照。
