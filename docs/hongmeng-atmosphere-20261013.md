# 鸿蒙云海：连续动态封面

实现日期：2026-10-13。接续验收日期：2026-10-14。

## 最新设计约束

- 不再使用宫殿、阁楼、天门、台阶等具象建筑。此前的“白金天庭 / 洪荒天阙”建筑方案已弃用。
- 保留白金色调，以云气、深远天光和汇流意象表达东方神话氛围与“海纳百川”。
- 云气、流光与微光必须协调、连续，不能像分块拼贴；文字区自然融入场景。
- 网站背景必须真正持续变化，不能以静态图片或预录视频替代动态设计。
- 正文、按钮和论文功能保持稳定；深色周天星空、开放链接结果与论文快照不回退。

## 实现

浅色封面现为本地 WebGL 实时流场。云体密度、受光边缘与流光共用同一噪声场，光沿云体轮廓流动，而不是在背景上叠加独立的硬线条。粒子跟随同一空间变换，中心天光轻微呼吸。固定随机种子稳定构图，时间连续推进，不循环切换背景图片。

文字区采用椭圆渐隐的雾层，云气可以自然延伸到文字周围，底部渐融入页面底色。背景有轻微、缓动的鼠标视差；文字及按钮不随之漂移。手机端根据画幅调整汇流中心，而不是截取桌面建筑局部。

- `frontend/src/components/HongmengScene.jsx`：画布、输入与 React 生命周期。
- `frontend/src/components/hongmengAtmosphere.js`：流场着色器、时间推进、渲染尺寸上限及 GPU 资源回收。
- `frontend/src/components/HongmengScene.css`：白金配色、雾化过渡、移动构图及降级动效。
- `frontend/src/components/MythicHero.jsx`：主题与动效控制；所有暂停状态传递给实时渲染器。
- `frontend/src/components/CelestialScene.jsx`：浅色场景分派；深色星图绘制函数未修改。

没有增加 npm 依赖，不请求远程图片、视频或模型服务。录屏只用于展示和验收，不是网站背景资源。

## 运行与可访问性

- 渲染缓冲不超过 480,000 像素，最长边不超过 1,440 像素；目标绘制频率最多 30 帧/秒，不承诺所有设备稳定达到该值。
- 键盘可暂停、恢复；系统减少动态效果、离开视口及切到后台均停止实时绘制。
- 暂停期间不积累动画时间，恢复时不会跳过一大段运动。
- WebGL 不可用或上下文丢失时，保留轻量 CSS 云雾与微光降级场景，不显示黑屏。
- 卸载时取消帧回调、移除观察器和事件监听、释放 GPU 资源。上下文回收延迟至微任务并核对所有权，避免 React StrictMode 在同一画布上重新挂载时错误销毁新渲染器。

## 本地预览与边界

在 `frontend` 目录执行：

```powershell
node node_modules/vite/bin/vite.js preview --host 127.0.0.1 --port 5185 --strictPort
```
