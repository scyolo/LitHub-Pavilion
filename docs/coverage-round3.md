## 本轮新增的采集能力

1. USENIX 技术论文目录：区分有正式论文的条目、主题报告、视频/幻灯片，严格检查会议路径和年份。
2. Springer 会议论文集：父书正式名称、会议届次、ISBN 与章节 DOI 联合核验；不把延迟出版年份当作会议年份。
3. Dagstuhl/LIPIcs、FMCAD：读取 DataCite 登记元数据，核对出版社、正式父卷、文章类型与 DOI；不把学生论坛、序言、整卷或预印本作为论文。
4. PACM、PVLDB、ICWSM、CHES/ToSC 等期刊发表型来源：验证 ISSN、容器标题、明确分期或正式系列；记录年份口径，不猜测展示届次。
5. CIDR、EDBT、Interspeech、I3D、MSST、NAACL、CogSci：解析官方逐届 HTML/XML/OAI 元数据与原文入口。CogSci OAI 请求严格限定其单一 source set，不抓取整个 eScholarship 仓库。
6. Crossref 游标查询显式按相关性排序，且每条候选仍需精确身份核验；已修复分卷标点、更名、学会前缀和日期错位导致的漏检。

## 会议与期刊关联：不重复论文

新增 paper_conferences 证据表，保存原论文 ID、会议、届次、证据 URL 和内容哈希。原始论文的 DOI、期刊归属、级别与发表年保持不变。

- Eurographics、EuroVis、EGSR、SGP、Pacific Graphics、SCA：核对 Eurographics 官方 CGF 专刊集合及具体论文；缺少卷期字段时另查 owningCollection，不靠猜测。
- ECSCW：官方 journal-papers 名单的完整题名和作者匹配后关联。
- IEEE VIS：只接受官网标为 VIS Full Papers 的长文；排除 workshop、short 和受邀合作展示，匹配既有 TVCG 论文。
- ISMB：官方 proceedings 展示名单与 Bioinformatics 论文的题名/作者核验。
- HiPEAC：官方 API 的 Paper Track、会议年与具体 DOI 名单核验，关联 TACO 原论文。

无法唯一匹配、题名冲突或原论文未通过公开准入的条目，写入本地冲突/未决报告，不强行合并。

## 性能和验证

大数据快照首次测得首页元数据 526,400 字节，略超原 512 KiB 门槛；该结果没有被视为通过，也没有提高预算。默认分片从 500 条调整为 1000 条（仍受 8 MiB 单文件限制），经回归验证后重新导出。

最终首页：**467,176 字节，2 个请求，0 个论文分片**，通过既有预算。

359,768 篇的标题索引身份全部核验；33 个精确标题、8 个智能匹配、19 个方向限制、8 个关键词 AND 检查通过；详情按需加载一个压缩分片。

Chromium 本机生产预览：无概览缓存首页 201 ms，延迟 manifest 5 秒时缓存首页 213 ms；这是本地测量，不代表公网或低端移动设备速度保证。关联页面已通过真实浏览器按需加载、证据链接、待核验筛选及移动布局检查。

最终后端 **842 项**、前端 **170 项**测试通过，生产构建通过；快照全部公开字段与当前数据库逐条一致（True）。具体记录见 release-artifacts/coverage-expansion 下的 backend-round3-final-tests.xml、source-coverage-browser-final.json、home-browser-round3-final.json 和 search-round3-final.json。
