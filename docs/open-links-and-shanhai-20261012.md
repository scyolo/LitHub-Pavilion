# 开放链接覆盖修复与山海封面（2026-10-12）

## 范围与原因

本次不新增论文、不改变正式发表归属或 CCF 范围、不下载 PDF、不删除历史归档，也未发布线上站点。

低覆盖包含两个可复现的遗漏：

1. 卡片与统计仅使用单独保存的 OA URL / arXiv，忽略了已收录的开放出版论文页；部分入库路径又优先用 DOI 覆盖 official_url，导致实际已知的开放入口未被利用。
2. OpenAlex 回填虽会处理 locations，但请求字段没有包含它，也未检查返回的 DOI 是否与已知论文冲突。采集器本身也漏掉了部分开放落地页与其他明确开放位置。

## 修复

- 新增集中式开放证据解析器；现有有效链接优先，论文级 URL 按精确主机与路径匹配，DOI 只对明确的开放出版系列派生入口。普通 DOI、混合 / 订阅出版页、会议节目单、平台首页、检索入口和不安全 URL 不会因此变成 OA。
- SQL 过滤 / 汇总、卡片与详情、静态快照统一复用解析器。新入库自动识别原始开放出版入口，避免后续再次遗漏。
- 分批遍历本地全库补全，重复运行不重复计数，不覆盖已有有效 URL，不改变 pdf_path / pdf_source。OpenAlex 完整请求 best_oa_location、open_access、primary_location、locations；身份冲突拒绝写入，401 / 403 / 429 保留断点。
- 首页解释“已找到 / 待发现”；详情优先呈现开放全文，官方页与开放全文相同时去重，另提供已知 arXiv 预印本及三个题名检索入口。检索入口不参与覆盖统计。

## 维护方式

在 backend 目录执行（必须先备份）：

```text
python -m scripts.backup
python -m scripts.backfill_links --local-only --report ../release-artifacts/open-links/local-report.json
python -m scripts.backfill_links --max-batches 20 --report ../release-artifacts/open-links/network-report.json
python -m scripts.export_snapshot --check-database
python -m scripts.export_source_audit --database data/papers.db --snapshot ../frontend/static/snapshot --output ../frontend/static/data-sources
```

第二个回填命令需要外网权限，只按 API 配额限速执行；不要循环绕过 401 / 403 / 429。本次本地验收结束时，修改与新快照尚未发布。2026-10-14 用户已授权推送仓库并更新网站；Git 提交、site-data 发布与 Pages 部署是独立步骤，最终以部署回执及线上 manifest 核对结果为准。
